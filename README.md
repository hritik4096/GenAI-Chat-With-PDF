# GenAI Chat With PDF

A Streamlit-based Generative AI application that allows users to upload PDF documents and ask questions from the PDF using Google Gemini AI, LangChain, and FAISS vector database.

## Features

- Upload multiple PDF files
- Extract text from PDFs
- Split text into chunks
- Generate embeddings using Google Generative AI
- Store embeddings using FAISS
- Ask questions from uploaded PDFs
- AI-generated contextual answers

## Tech Stack

- Python
- Streamlit
- LangChain
- Google Gemini AI
- FAISS
- PyPDF2
